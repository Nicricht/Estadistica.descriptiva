# Material de referencia del profesor

Esta carpeta contiene notebooks resueltos entregados por el profesor y se conserva como referencia para desarrollar el notebook principal del proyecto.

## Archivos
- `Soluciones_Laboratorio 1_Conceptos básicos de estadística.ipynb`
- `Soluciones_Laboratorio 3_Gráficos.ipynb`
- `Soluciones_Laboratorio 5_Medidas de Dispersión.ipynb`

## Uso dentro del proyecto
Estos notebooks sirven como patrón para mantener:
- estructura de pregunta → código → resultado → interpretación;
- uso de herramientas estadísticas vistas en clases;
- nivel de complejidad del código;
- forma de construir tablas y gráficos;
- forma de redactar conclusiones descriptivas.

El archivo `Soluciones_Laboratorio 3_Gráficos (1).ipynb` no se agregó una segunda vez porque es una copia idéntica del notebook de Gráficos.
